# Security / 安全反馈

Please do not publish credentials, private question text or local draft backups in an issue. If the repository's Security tab offers private vulnerability reporting, use it for security-sensitive findings. Otherwise start with a general issue asking for a private reporting channel without including exploit details or private data.

涉及敏感内容时，优先使用仓库 Security 页面提供的私密反馈；若未启用，先发不含细节的 Issue 询问私密渠道。不要上传令牌、账号数据或草稿备份。

Only the current preview is maintained. Download artifacts from this repository's Releases and compare SHA-256 checksums. Artifacts are not Authenticode-signed. The checksum verifies the downloaded artifact against the published digest; it is not a publisher signature.

The project does not include an updater, remote control endpoint or API credentials. Windows foreground restrictions, secure-desktop restrictions and destination-app permissions remain in force.
